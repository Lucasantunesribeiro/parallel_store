# Parallel Store

E-commerce urbano criado com Next.js 15, React 18 e Tailwind. Consulte `PROMPT_CODEX.md` para o manifesto completo.

## Scripts
- `npm run dev` – desenvolvimento
- `npm run build` – build de produção
- `npm run start` – executa build
- `npm run lint` – ESLint
- `npm run type-check` – TypeScript
- `npm run format` – Prettier

## Estrutura
Consulte `tailwind.config.ts`, `app/` e `components/` para convenções. Apis e integrações Supabase estão em `lib/` e `app/api/*`.
